## 🎯 关键特性

### 并行执行

- ✅ CAD 拆图完成后立即启动
- ✅ 特征识别 + NC 时间计算同时进行
- ✅ 节省约 28.6% 的执行时间

### 时间分类

- **精铣**：包含"精"字 → `nc_milling_time`
- **开粗**：包含"粗"字 → `nc_roughing_time`
- **钻孔**：`_M_`, `_L_`, `_ZXZ` → `drilling_time`

### 错误处理

- 特征识别失败 → 阻断流程
- NC 计算失败 → 只记录警告，继续执行

## 📝 常见问题

### Q1: NC Agent 连接失败？

**检查：**
```bash
curl http://nc-agent:8001/health
```

**解决：**
- 确认 NC Agent 服务已启动
- 检查 .env 中的 NC_AGENT_URL 配置

### Q2: 子图名称映射失败？

**检查：**
```sql
SELECT subgraph_id FROM subgraphs WHERE job_id = 'xxx';
```

**解决：**
- 确认子图 ID 格式为 `xxx_PH-01` 形式

### Q3: 时间数据为空？

**检查：**
- NC Agent 返回的 JSON 格式
- operations 中是否有 `Toolpath Time` 参数
