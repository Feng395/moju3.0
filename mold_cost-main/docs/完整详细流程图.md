## 四、流程图说明

### 4.1 核心特点

1. **完整性 (Completeness)**
   - 覆盖从文件上传到归档的完整流程
   - 包含所有8个阶段的详细步骤
   - 包含重算功能和4种特殊场景

2. **并行处理 (Parallel Processing)**
   - 特征识别和NC时间计算并行执行
   - 多个子图并行处理(最多8个线程)
   - 多工艺Agent并行执行

3. **用户交互 (User Interaction)**
   - 参数缺失时生成交互卡片
   - 支持用户输入和重新识别
   - 工作流暂停等待用户操作

4. **错误处理 (Error Handling)**
   - 超时重试机制(3次,指数退避)
   - 降级策略(使用默认值/历史平均值)
   - 详细的错误日志记录

5. **审计追踪 (Audit Trail)**
   - 完整的操作日志记录
   - 用户交互记录
   - 价格历史快照
   - 7年归档保留

6. **可扩展性 (Extensibility)**
   - 支持动态加载Agent
   - 支持多工艺并行处理
   - 支持工艺变更(线割改精铣)
   - 支持板料线生成等扩展功能

### 4.2 技术要点

1. **MCP服务调用**
   - 所有Agent通过MCP服务实现具体功能
   - 统一的接口规范(BaseAgent)
   - 外部NC Agent使用独立HTTP接口

2. **数据库设计**
   - 14张表支持完整业务流程
   - 审计表记录所有操作
   - 价格历史表支持版本追溯

3. **并发控制**
   - RabbitMQ队列管理任务
   - ThreadPoolExecutor处理子图
   - asyncio.gather处理异步调用

4. **实时通信**
   - WebSocket推送任务进度
   - 前端实时显示状态更新
   - 支持卡片交互

### 4.3 中英文注释

所有流程图中的英文命名都添加了中文注释,确保团队成员能够清晰理解每个步骤的含义。
