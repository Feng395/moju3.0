# Agent 输入/输出数据流图

> 可视化展示从 RabbitMQ 消息到最终报表的完整数据流

---

## 一、整体数据流

```
┌─────────────────────────────────────────────────────────────────┐
│                         RabbitMQ                                │
│                                                                 │
│  Queue: job_processing                                          │
│  Message: {                                                     │
│    "job_id": "a1b2c3d4-...",                                   │
│    "user_id": "user_789",                                      │
│    "created_at": "2026-01-12T10:15:30"                        │
│  }                                                             │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│              OrchestratorAgent 消费消息                         │
│                                                                 │
│  1. 读取 Job 表 (job_id)                                        │
│  2. 初始化 OrchestratorState                                    │
│  3. 启动 LangGraph StateGraph 工作流                            │
└─────────────────────────────────────────────────────────────────┘
                            ↓
┌─────────────────────────────────────────────────────────────────┐
│                   OrchestratorState                             │
│  ┌───────────────────────────────────────────────────────────┐ │
│  │ job_id: "a1b2c3d4-..."                                    │ │
│  │ session_id: "sess_20260112_103530"                        │ │
│  │ current_stage: "initializing" → "cad_parsing" → ...       │ │
│  │                                                            │ │
│  │ agent_outputs: {}                                          │ │
│  │ subgraphs: []                                              │ │
│  │ features: []                                               │ │
│  │ pricing_results: null                                      │ │
│  │ errors: []                                                 │ │
│  └───────────────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────────────────┘
                            ↓
                    ┌───────────────┐
                    │   开始工作流   │
                    └───────────────┘
```

## 九、关键设计点总结

### 1. **State 是数据流的中心**
- 所有 Agent 输出都收集到 `state["agent_outputs"]`
- 业务数据累积在 `state["subgraphs"]`, `state["features"]` 等

### 2. **Agent 低耦合**
- Agent 只接收标准 `AgentContext`
- Agent 不知道上游/下游是谁
- 依赖关系由编排器管理

### 3. **快照隔离保证一致性**
- 价格/工艺规则在 Job 创建时快照
- Agent 只读快照表，不读主表
- 版本锁定在 `snapshot_refs`

### 4. **完整审计追踪**
- 每个 Agent 执行都有唯一 `execution_id`
- 输入/输出都记录到 `agent_execution_logs`
- State 快照保存到 `orchestration_sessions`

### 5. **错误可恢复**
- 每个 Stage 完成后创建检查点
- 错误标记 `is_retryable`
- 支持从任意 Stage 恢复
