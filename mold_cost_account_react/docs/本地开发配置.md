# 🔧 本地开发环境配置

## ✅ 问题已解决

**根本原因**: 前端 `.env` 文件配置的API地址是远程服务器 `http://192.168.0.41:8211`，而不是本地的 `http://localhost:8000`

## 📝 已修复的配置

### 修改前（错误）
```env
VITE_API_BASE_URL=http://192.168.0.41:8211  # ❌ 远程地址
VITE_API_PREFIX=/api/v1                      # ❌ 旧的前缀
```

### 修改后（正确）
```env
VITE_API_BASE_URL=http://localhost:8000      # ✅ 本地地址
VITE_API_PREFIX=/api                         # ✅ 新的前缀
```

## 🚀 立即生效

**重启前端服务**:

```bash
# 1. 停止前端（在前端终端按 Ctrl+C）

# 2. 重新启动
npm run dev
```

## 📋 配置文件说明

### `.env` - 默认配置
- 已更新为本地开发配置
- 所有API指向 `http://localhost:8000`

### `.env.local` - 本地开发专用（新创建）
- 优先级高于 `.env`
- 用于本地开发环境
- 不会被提交到Git

### `.env.production` - 生产环境
- 用于生产部署
- 指向生产服务器地址

## 💡 环境切换

### 本地开发
使用 `.env.local` 或 `.env`（已配置为本地）

### 连接远程服务器
创建 `.env.remote`:
```env
VITE_API_BASE_URL=http://192.168.0.41:8211
VITE_API_PREFIX=/api/v1
```

然后：
```bash
# 使用远程配置启动
npm run dev -- --mode remote
```
