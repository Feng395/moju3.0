# 麦克风功能测试指南

## 🚀 快速测试

### 1. 启动所有服务

```bash
cd mold_cost_
start_all.bat
```

等待所有服务启动：
- ✅ MCP Services (端口 8200)
- ✅ API Gateway + Workers (端口 8000)
- ✅ Speech Services (端口 8888)
- ✅ Frontend (端口 5173)

### 2. 打开浏览器

访问：http://localhost:5173

### 3. 测试麦克风

1. **点击麦克风按钮**（右下角输入框旁边）
2. **允许麦克风权限**（浏览器会弹出提示）
3. **开始说话**（例如："将 UP01 的材质改为 718"）
4. **点击停止按钮**
5. **查看识别结果**（应该显示在输入框中）

## 🐛 故障排除

### 问题 1：麦克风权限被拒绝

**症状**：
```
❌ 启动录音失败: NotAllowedError
```

**解决**：
1. 点击地址栏左侧的锁图标
2. 找到"麦克风"权限
3. 改为"允许"
4. 刷新页面（F5）

### 问题 2：识别请求失败 503

**症状**：
```
❌ 识别请求失败: 503 Service Unavailable
```

**解决**：
```bash
# 检查 Speech Services 是否运行
curl http://localhost:8888/api/health

# 如果没有响应，启动服务
cd mold_cost_/speech_services
start_speech.bat
```

### 问题 3：识别结果为空

**症状**：
- 录音正常
- 没有错误
- 但识别结果为空

**可能原因**：
- 录音时间太短（< 0.5 秒）
- 环境噪音太大
- 没有说话

**解决**：
- 录音至少 1-2 秒
- 在安静环境测试
- 清晰地说话

### 问题 4：识别速度慢

**症状**：
- 停止录音后等待很久
- 识别结果延迟 10+ 秒

**可能原因**：
- 使用了大模型（medium/large）
- CPU 性能不足
- 没有使用 GPU

**解决**：
```bash
# 使用更小的模型
cd mold_cost_/speech_services
python main.py --model tiny  # 最快
python main.py --model small # 推荐

# 或启用 GPU 加速
# 参见 GPU_SETUP.md
```

### 问题 5：浏览器显示"不支持麦克风"

**症状**：
```
您的浏览器不支持麦克风功能
```

**解决**：
1. 确认使用的是 Chrome/Edge/Firefox 等现代浏览器
2. 清除浏览器缓存：`Ctrl + Shift + R`
3. 检查前端代码是否已更新（参见 MICROPHONE_FIX.md）

## 🎯 最佳实践

### 录音技巧

1. **清晰发音**：说话清晰，不要含糊
2. **适当停顿**：句子之间稍作停顿
3. **控制时长**：每次录音 5-15 秒为宜
4. **安静环境**：减少背景噪音

### 使用建议

1. **短句优先**：将长句拆分为多个短句
2. **及时确认**：识别后检查结果是否正确
3. **手动修正**：识别错误时手动修正
4. **学习功能**：系统会学习你的常用术语

### 性能优化

1. **使用 small 模型**：平衡速度和准确率
2. **启用 GPU**：大幅提升识别速度
3. **减少并发**：避免同时多个识别请求
4. **网络优化**：确保网络连接稳定
