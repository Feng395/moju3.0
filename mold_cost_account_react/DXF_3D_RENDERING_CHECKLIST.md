## 🔧 技术规格

### 依赖库
```json
{
  "dxf-viewer": "^1.0.46"
}
```

### 核心API
```typescript
// 创建查看器
const viewer = new DxfViewer(container, {
  clearColor: 0xffffff,      // 白色背景
  autoResize: true,          // 自动调整大小
  colorCorrection: true      // 颜色校正
})

// 加载DXF文件
await viewer.Load(presignedUrl)

// 适应视图
viewer.FitView()

// 销毁查看器
viewer.Destroy()
```
