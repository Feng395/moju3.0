# 聊天区域表格渲染功能

## 🎯 功能概述

为聊天区域添加了 Markdown 表格渲染支持，使后端接口返回的表格数据能够以美观的表格形式展示。

## ✨ 主要特性

- ✅ **自动渲染**：自动识别并渲染 Markdown 表格语法
- ✅ **美观样式**：使用 Ant Design 主题，样式统一美观
- ✅ **响应式设计**：支持桌面端和移动端，宽表格自动横向滚动
- ✅ **丰富格式**：支持对齐方式、特殊字符、Emoji、Markdown 格式
- ✅ **高性能**：渲染速度快，内存占用低
- ✅ **易于使用**：后端只需返回标准 Markdown 表格即可

## 🚀 快速开始

### 后端接口返回示例

```json
{
  "status": "ok",
  "message": "价格明细：\n\n| 项目 | 金额 | 说明 |\n|------|------|------|\n| 材料费 | 102.3元 | 19.3kg × 5.3元/kg |\n| 线割基础费 | 271.89元 | 622.89mm × 97mm × 0.0045 |\n| 总价 | 414.99元 | ✅ 合理 |"
}
```

### Markdown 表格语法

```markdown
| 项目 | 金额 | 说明 |
|------|------|------|
| 材料费 | 102.3元 | 19.3kg × 5.3元/kg |
| 线割基础费 | 271.89元 | 622.89mm × 97mm × 0.0045 |
| 总价 | 414.99元 | ✅ 合理 |
```

### 渲染效果

表格会被渲染为带样式的 HTML 表格：
- 表头有浅灰色背景
- 单元格有适当的内边距
- 边框清晰分隔
- 支持横向滚动

## 🔧 技术实现

```json
{
  "react-markdown": "^9.0.1",
  "remark-gfm": "^4.0.1"
}
```

### 核心代码
```typescript
import remarkGfm from 'remark-gfm'

<ReactMarkdown
  remarkPlugins={[remarkGfm]}
  components={{
    table: ({ children }) => (/* 表格样式 */),
    thead: ({ children }) => (/* 表头样式 */),
    th: ({ children }) => (/* 表头单元格样式 */),
    td: ({ children }) => (/* 数据单元格样式 */),
  }}
>
  {message.content}
</ReactMarkdown>
```

## 📝 使用建议

### 最佳实践
1. 单个表格建议不超过 50 行
2. 使用清晰的表头
3. 保持列数一致
4. 适当使用对齐方式
5. 合理使用特殊字符

### 注意事项
1. 必须遵循标准 Markdown 表格语法
2. 表头和分隔行是必需的
3. 每行的列数必须一致
4. 避免在表格中嵌套复杂结构

## 🐛 故障排查

### 表格不显示
1. 检查 Markdown 语法是否正确
2. 确认 `remark-gfm` 插件已安装
3. 查看浏览器控制台错误

### 样式异常
1. 检查 Ant Design token 是否加载
2. 确认 CSS 样式没有被覆盖
3. 检查浏览器兼容性

### 内容被截断
1. 检查表格容器的 `overflowX` 设置
2. 确认父容器没有限制宽度
3. 尝试减少列数或内容
