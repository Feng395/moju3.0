  # 访问控制台

  # 默认账号: minioadmin/minioadmin

  RABBITMQ_HOST=localhost

  ```

### 3. 数据库初始化

- [ ] 创建数据库

  ```

- [ ] 运行迁移脚本（如果有）

## 🐛 常见问题

### 问题 1: MinIO 连接失败

**错误信息：**
```
AttributeError: 'NoneType' object has no attribute 'lower'
```

**解决方案：**
1. 检查 `.env` 文件是否包含 MinIO 配置
2. 确认环境变量名称正确：
   - 使用 `MINIO_SECURE` 而不是 `MINIO_USE_HTTPS`
   - 使用 `MINIO_BUCKET_FILES` 或 `MINIO_BUCKET`
3. 参考文档：`docs/config/MINIO_ENV_FIX.md`

### 问题 2: 数据库连接失败

**错误信息：**
```
could not connect to server: Connection refused
```

**解决方案：**
1. 确认 PostgreSQL 服务已启动
2. 检查数据库配置是否正确
3. 验证数据库是否已创建

### 问题 3: RabbitMQ 连接失败

**错误信息：**
```
AMQPConnectionError: Connection refused
```

**解决方案：**
1. 确认 RabbitMQ 服务已启动
2. 检查端口 5672 是否被占用
3. 验证用户名和密码是否正确

### 问题 4: Redis 连接失败

**错误信息：**
```
ConnectionError: Error connecting to Redis
```

**解决方案：**
1. 确认 Redis 服务已启动
2. 检查端口 6379 是否被占用
3. 验证 Redis URL 配置是否正确

## 📝 开发建议

### 开发模式配置

在 `.env` 文件中设置：
```bash
DEBUG=true
RELOAD=true
LOG_LEVEL=DEBUG
```

### 生产模式配置

在 `.env` 文件中设置：
```bash
DEBUG=false
RELOAD=false
LOG_LEVEL=INFO
ENABLE_JSON_LOG=true
```

### 性能优化

1. **数据库连接池**：
   ```bash
   DB_POOL_SIZE=10
   DB_MAX_OVERFLOW=5
   ```

2. **MinIO 上传优化**：
   ```bash
   MINIO_UPLOAD_PART_SIZE=10485760  # 10MB
   MINIO_UPLOAD_WORKERS=5
   ```

3. **API 超时设置**：
   ```bash
   API_TIMEOUT=60
   LLM_TIMEOUT=300
   NC_AGENT_TIMEOUT=86400
   ```

## ✨ 快速启动脚本

创建一个启动脚本 `start_all.sh`：

```bash
#!/bin/bash

# 启动 API Gateway
echo "🚀 启动 API Gateway..."
cd mold_cost_
uvicorn api_gateway.main:app --host 0.0.0.0 --port 8000 --reload &
API_PID=$!

# 等待 API Gateway 启动
sleep 5

# 启动 Worker
echo "🚀 启动 Orchestrator Worker..."
python workers/orchestrator_worker.py &
WORKER_PID=$!

echo "✅ 所有服务已启动"
echo "API Gateway PID: $API_PID"
echo "Worker PID: $WORKER_PID"
echo ""
echo "访问 API 文档: http://localhost:8000/docs"
echo ""
echo "按 Ctrl+C 停止所有服务"

# 等待中断信号
trap "kill $API_PID $WORKER_PID; exit" INT
wait
```

使用方法：
```bash
chmod +x start_all.sh
./start_all.sh
```
