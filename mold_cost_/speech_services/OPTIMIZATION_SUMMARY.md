### 2. 更新字典管理器

**文件**: `core/dict_manager.py`

**改进**:
- 优先加载模具行业字典
- 保持向后兼容（回退到程序员术语字典）
- 添加调试日志，显示使用的字典

**代码变更**:
```python
def _get_dict_file_path(self) -> Optional[str]:
    # 优先使用模具行业字典
    mold_dict = os.path.join(root, 'dictionaries', 'mold_industry_terms.json')
    if os.path.exists(mold_dict):
        return mold_dict
    
    # 回退到程序员术语字典
    default_path = os.path.join(root, 'dictionaries', 'programmer_terms.json')
    return default_path if os.path.exists(default_path) else None
```

## 🔧 使用方法

### 1. 启动服务

```bash
cd mold_cost_/speech_services
python main.py --model small --host 0.0.0.0 --port 8888
```

### 2. 运行测试

```bash
python test_mold_speech.py
```

### 3. API 调用

```python
import requests

with open('audio.wav', 'rb') as f:
    files = {'file': f}
    data = {
        'model': 'small',
        'language': 'zh',
        'fix_terms': 'true',
        'learn': 'true'
    }
    
    response = requests.post(
        'http://localhost:8888/api/transcribe',
        files=files,
        data=data
    )
    
    result = response.json()
    print(f"识别结果: {result['text']}")
    print(f"修正次数: {result['corrections']['count']}")
```

## 📝 关键改进点

### 1. 字典结构优化

**问题**: 原有字典主要针对程序员术语，不适合模具行业

**解决**: 
- 创建专门的模具行业字典
- 保持相同的结构，便于维护
- 支持自动切换，无需修改代码

### 2. 术语识别优化

**问题**: 模具行业术语复杂，包含中英文混合、数字、特殊符号

**解决**:
- 针对每个术语添加多个常见误识别变体
- 支持大小写转换（UP01 ↔ up01）
- 支持数字中文化（修一 ↔ 修1）
- 支持特殊符号（45# ↔ 45号）

### 3. 概念词支持

**问题**: 用户经常使用概念词进行批量修改（如"冲头类"）

**解决**:
- 添加概念词类别
- 包含常见的零件类型概念
- 支持概念词的误识别修正

### 4. 学习功能增强

**问题**: 用户习惯需要快速学习

**解决**:
- 降低学习频率阈值（3 → 2）
- 增加用户术语上限（20 → 30）
- 增加提示词术语数量（10 → 15）

## 🎨 字典维护

### 添加新术语

1. 打开 `dictionaries/mold_industry_terms.json`
2. 找到对应类别
3. 添加术语定义：

```json
"新术语": {
  "correct": "新术语",
  "description": "术语说明",
  "variants": [
    {"wrong": "错误识别1", "description": "原因"},
    {"wrong": "错误识别2", "description": "原因"}
  ]
}
```

### 添加新类别

```json
"new_category": {
  "name": "新类别",
  "description": "类别说明",
  "terms": {
    // 术语定义
  }
}
```
