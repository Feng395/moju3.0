# 价格项接口文档（简洁版）

## 基础信息
- **服务地址**: `http://192.168.0.14:8000`
- **接口前缀**: `/api/price-items`
- **数据格式**: JSON

---

## 接口总览

| 序号 | 接口 | 方法 | 说明 |
|------|------|------|------|
| 1 | `/api/price-items` | POST | 创建价格项 |
| 2 | `/api/price-items/{id}` | GET | 获取单个价格项 |
| 3 | `/api/price-items` | GET | 获取价格项列表 |
| 4 | `/api/price-items/{id}` | PUT | 更新价格项 |
| 5 | `/api/price-items/{id}` | DELETE | 删除价格项 |
| 6 | `/api/price-items/batch-delete` | POST | 批量删除 |
| 7 | `/api/price-items/by-version-category` | GET | 按版本和类别查询 |

---

## 1. 创建价格项

**POST** `/api/price-items`

**请求示例**:
```json
{
  "id": "P001",
  "version_id": "v1.0",
  "category": "wire",
  "sub_category": "线割加工",
  "price": "100.00",
  "unit": "元/小时",
  "work_hours": "1.5",
  "min_num": "50",
  "add_price": "10.00",
  "weight_num": "1.2",
  "note": "备注",
  "instruction": "计算说明",
  "is_active": true,
  "created_by": "admin"
}
```

**必填字段**: `id`

---

## 2. 获取单个价格项

**GET** `/api/price-items/{id}`

**示例**: `GET /api/price-items/P001`

---

## 3. 获取价格项列表

**GET** `/api/price-items`

**查询参数**:
- `page`: 页码（默认1）
- `page_size`: 每页数量（默认20）
- `version_id`: 版本号筛选
- `category`: 类别筛选（wire/special/base）
- `sub_category`: 子类筛选（模糊）
- `is_active`: 是否激活

**示例**:
```bash
GET /api/price-items?version_id=v1.0&category=wire&page=1&page_size=20
```

**响应格式**:
```json
{
  "success": true,
  "message": "获取成功",
  "data": {
    "total": 100,
    "page": 1,
    "page_size": 20,
    "total_pages": 5,
    "data": [...]
  }
}
```

---

## 4. 更新价格项

**PUT** `/api/price-items/{id}`

**请求示例**:
```json
{
  "price": "150.00",
  "note": "更新后的备注",
  "is_active": false
}
```

**说明**: 所有字段可选，只更新提供的字段

---

## 5. 删除价格项

**DELETE** `/api/price-items/{id}`

**示例**: `DELETE /api/price-items/P001`

---

## 6. 批量删除

**POST** `/api/price-items/batch-delete`

**请求示例**:
```json
{
  "ids": ["P001", "P002", "P003"]
}
```

---

## 7. 按版本和类别查询

**GET** `/api/price-items/by-version-category`

**查询参数**:
- `version_id`: 版本号（必填）
- `category`: 类别（必填）
- `active_only`: 只返回激活的（默认true）

**示例**:
```bash
GET /api/price-items/by-version-category?version_id=v1.0&category=wire
```

---

## 数据字段说明

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string(50) | 价格项ID（必填） |
| version_id | string(50) | 版本号 |
| category | string(100) | 类别（wire/special/base） |
| sub_category | string(200) | 子类 |
| price | string(50) | 单价 |
| unit | string(50) | 单位 |
| work_hours | string(50) | 工时 |
| min_num | string(50) | 最低计费标准 |
| add_price | string(50) | 附加费 |
| weight_num | string(50) | 重量计算系数 |
| note | string(500) | 备注 |
| instruction | string(500) | 计算说明 |
| is_active | boolean | 是否激活 |
| created_by | string(100) | 创建人 |
| created_at | timestamp | 创建时间（自动） |
| updated_at | timestamp | 更新时间（自动） |

## 快速测试

### 创建
```bash
curl -X POST http://192.168.0.14:8000/api/price-items \
  -H "Content-Type: application/json" \
  -d '{"id":"P001","version_id":"v1.0","category":"wire","price":"100.00"}'
```

### 查询列表
```bash
curl "http://192.168.0.14:8000/api/price-items?version_id=v1.0"
```

### 更新
```bash
curl -X PUT http://192.168.0.14:8000/api/price-items/P001 \
  -H "Content-Type: application/json" \
  -d '{"price":"150.00"}'
```

### 删除
```bash
curl -X DELETE http://192.168.0.14:8000/api/price-items/P001
```

## 状态码

| 状态码 | 说明 |
|--------|------|
| 200 | 成功 |
| 201 | 创建成功 |
| 400 | 参数错误 |
| 404 | 不存在 |
| 500 | 服务器错误 |

---

## 注意事项

1. ⚠️ **所有数值字段都是字符串类型**（price、work_hours等）
2. ⏰ **时间格式**: `2026-01-12T15:58:47`
3. 🔄 **updated_at自动更新**
4. 📝 **id必须唯一**
5. 🔍 **sub_category支持模糊搜索**

## Python示例

```python
import requests

base = "http://192.168.0.14:8000/api/price-items"

# 创建
data = {"id": "P001", "version_id": "v1.0", "price": "100.00"}
r = requests.post(base, json=data)

# 查询
r = requests.get(f"{base}?version_id=v1.0")

# 更新
r = requests.put(f"{base}/P001", json={"price": "150.00"})

# 删除
r = requests.delete(f"{base}/P001")
```

## JavaScript示例

```javascript
const base = 'http://192.168.0.14:8000/api/price-items';

fetch(`${base}/P001`, {method: 'DELETE'});
```
