# Gemini风格界面特性

## 🎨 设计特色

### 完全仿照Google Gemini界面
- **顶部搜索栏**: 居中的搜索框，右侧用户头像
- **左侧边栏**: 可折叠的导航栏，包含新建会话和历史记录
- **欢迎页面**: "Hi Aria, Where should we start?" 的问候语
- **快捷操作**: Create image, Create video, Write anything, Find inspiration
- **建议按钮**: Help me learn, Boost my day

### 颜色方案
- **主色调**: Google蓝 (#1a73e8)
- **背景色**: 浅灰 (#f8f9fa)
- **文字色**: 深灰 (#202124, #3c4043, #5f6368)
- **边框色**: 浅灰 (#dadce0, #e8eaed)

### 字体
- **主字体**: Google Sans
- **备用字体**: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto

## 🔧 界面组件

### 侧边栏 (Sidebar)
- **汉堡菜单**: 左上角三条线图标
- **Gemini标题**: 品牌标识
- **新建聊天**: 圆角按钮，带加号图标
- **我的内容**: "My Stuff" 分组标题
- **历史对话**: 可点击的对话列表
- **设置帮助**: 底部设置按钮

### 顶部栏 (Header)
- **搜索框**: 居中的圆角搜索框，带搜索图标
- **用户头像**: 右侧圆形头像，可点击下拉菜单

### 主内容区 (Content)
- **欢迎标题**: 大号字体 "Hi Aria"
- **副标题**: "Where should we start?"
- **快捷操作**: 4个圆角按钮，带彩色图标
- **建议按钮**: 小号圆角按钮

### 输入区域 (Input)
- **文本框**: 圆角文本域，右侧发送按钮
- **占位符**: "Ask Gemini 3"
- **发送按钮**: 圆形按钮，带箭头图标

## 📱 响应式设计

### 桌面端 (>768px)
- 侧边栏完全展开 (280px宽度)
- 搜索栏居中显示
- 快捷操作按钮网格布局

### 移动端 (<768px)
- 侧边栏自动折叠
- 搜索栏适配小屏幕
- 快捷操作按钮单列布局

## 🎯 交互效果

### 悬停效果
- 按钮悬停时轻微上移
- 颜色渐变过渡
- 阴影增强

### 点击反馈
- 按钮点击时缩放效果
- 状态变化动画
- 加载指示器

### 过渡动画
- 侧边栏展开/收起动画
- 页面切换淡入效果
- 消息发送动画

## 🚀 使用说明

1. **新建会话**: 点击左侧 "New chat" 按钮
2. **历史记录**: 在 "My Stuff" 下查看历史对话
3. **快捷操作**: 点击主页的彩色按钮快速开始
4. **搜索**: 使用顶部搜索框查找内容
5. **设置**: 点击左下角设置按钮进入设置页面

## 📝 开发说明

### CSS类名规范
- `.gemini-*`: Gemini风格的组件样式
- `.quick-action-*`: 快捷操作相关样式
- `.suggestion-*`: 建议按钮样式
- `.conversation-*`: 对话相关样式

### 组件结构
```
ChatPage
├── Sidebar (左侧边栏)
├── Header (顶部搜索栏)
└── Content (主内容区)
    ├── Welcome (欢迎页面)
    ├── Messages (聊天消息)
    └── Input (输入区域)
```

### 状态管理
- 使用Zustand管理全局状态
- 会话历史自动保存
- 响应式布局状态同步
