# 价格项接口文档

## 基础信息

**服务地址**: `http://192.168.0.14:8000`  
**接口前缀**: `/api/price-items`  
**数据格式**: JSON

---

## 数据模型

### PriceItem 对象

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string(50) | 是 | 价格项唯一标识，如P001 |
| version_id | string(50) | 否 | 价格版本号 |
| category | string(100) | 否 | 类别（wire-线割, special-特殊加工费, base-基本加工费） |
| sub_category | string(200) | 否 | 子类 |
| price | string(50) | 否 | 单价 |
| unit | string(50) | 否 | 单位 |
| work_hours | string(50) | 否 | 工时 |
| min_num | string(50) | 否 | 最低计费标准 |
| add_price | string(50) | 否 | 附加费 |
| weight_num | string(50) | 否 | 重量计算系数 |
| note | string(500) | 否 | 备注 |
| instruction | string(500) | 否 | 计算说明 |
| is_active | boolean | 否 | 是否激活（默认true） |
| created_by | string(100) | 否 | 创建人 |
| created_at | timestamp | 自动 | 创建时间 |
| updated_at | timestamp | 自动 | 更新时间 |

```bash

  -H "Content-Type: application/json" \
  -d '{
    "id": "P001",
    "version_id": "v1.0",
    "category": "wire",
    "sub_category": "线割加工",
    "price": "100.00",
    "unit": "元/小时"
  }'

# 2. 获取单个价格项

# 4. 更新价格项
curl -X PUT http://192.168.0.14:8000/api/price-items/P001 \
  -H "Content-Type: application/json" \
  -d '{
    "price": "150.00",
    "note": "更新后的备注"
  }'

# 5. 删除价格项
curl -X DELETE http://192.168.0.14:8000/api/price-items/P001

# 6. 批量删除
curl -X POST http://192.168.0.14:8000/api/price-items/batch-delete \
  -H "Content-Type: application/json" \
  -d '{
    "ids": ["P001", "P002"]
  }'

# 7. 根据版本和类别获取
curl "http://192.168.0.14:8000/api/price-items/by-version-category?version_id=v1.0&category=wire"
```

### Python示例

```python
import requests

base_url = "http://192.168.0.14:8000/api/price-items"

# 创建价格项
item_data = {
    "id": "P001",
    "version_id": "v1.0",
    "category": "wire",
    "sub_category": "线割加工",
    "price": "100.00",
    "unit": "元/小时"
}
response = requests.post(base_url, json=item_data)
print(response.json())

# 获取价格项列表
response = requests.get(base_url, params={"version_id": "v1.0"})
print(response.json())

# 更新价格项
update_data = {"price": "150.00", "note": "更新后的备注"}
response = requests.put(f"{base_url}/P001", json=update_data)
print(response.json())

# 删除价格项
response = requests.delete(f"{base_url}/P001")
print(response.json())
```

## 注意事项

1. **字段类型**
   - 所有数值字段（price、work_hours等）都是VARCHAR类型，存储为字符串
   - 需要在应用层进行数值转换和计算

2. **唯一性约束**
   - `id` 字段必须唯一
   - 重复的ID会导致创建失败

3. **自动更新时间**
   - `updated_at` 字段在更新时会自动更新
   - 由数据库触发器自动处理

4. **激活状态**
   - 默认情况下，`by-version-category` 接口只返回激活的价格项
   - 可通过 `active_only=false` 参数获取所有价格项

5. **分页限制**
   - 默认每页20条记录
   - 建议最大每页100条记录
